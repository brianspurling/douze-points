# US States Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a third menu option, **USA**, that swaps the map to a US-states topojson and runs the existing 25-round game (Eurovision shell unchanged) against all 50 states. SVG state flags replace emoji in the UI; postal abbreviations replace them in share text.

**Architecture:** All JS/CSS/HTML changes stay in the single `index.html` (vanilla, no build step). The existing `EU_*` lat/lon constants and `COUNTRY_SETS` collapse into a single `REGIONS` descriptor keyed by region name (eurovision / europe / usa); each entry carries its data source key, bbox, and playable-name set. A new `loadSource()` helper lazy-loads the per-source topojson (world-atlas for EU/Eurovision, us-atlas for USA) and caches the result. A new `flagHTML(name)` helper returns either an emoji string (for `source: 'world'` regions) or an `<img>` element pointing to `flags/us-XX.svg` (for `source: 'us'`). State flag SVGs are committed to a new `flags/` directory alongside `audio/`.

**Tech Stack:** Vanilla HTML/CSS/JS, D3 v7 (already loaded via jsDelivr), topojson-client (already loaded), `world-atlas@2` (already used), `us-atlas@3` (new, jsDelivr). No build step. No test framework — verification is manual via the browser preview tools (`preview_start`, `preview_resize`, `preview_screenshot`, `preview_snapshot`, `preview_console_logs`).

**Spec:** [docs/superpowers/specs/2026-05-18-us-states-design.md](../specs/2026-05-18-us-states-design.md)

```js
      const mercY = lat => Math.log(Math.tan(Math.PI / 4 + (lat * Math.PI / 180) / 2));

```

Replace with:

```js
    function buildProjection([w, h], bbox) {
      const [west, east, south, north] = bbox;
      const mercY = lat => Math.log(Math.tan(Math.PI / 4 + (lat * Math.PI / 180) / 2));
      const lonSpan = (east - west) * Math.PI / 180;
      const latSpan = mercY(north) - mercY(south);
      // Scale so the bbox FITS inside the viewport — no part of the region is cropped.
      const scale = Math.min(w / lonSpan, h / latSpan);
      const centerLon = (west + east) / 2;
      const centerLat = (south + north) / 2;
      return d3.geoMercator()
        .scale(scale)
        .center([centerLon, centerLat])
        .translate([w / 2, h / 2]);
    }
```

```js
        url: 'https://cdn.jsdelivr.net/npm/world-atlas@2/countries-50m.json',
        objectKey: 'countries',

    const topoCache = {};
    async function loadSource(key) {
      if (topoCache[key]) return topoCache[key];
      const def = SOURCES[key];
      const topo = await d3.json(def.url);
      const features = topojson.feature(topo, topo.objects[def.objectKey]).features;
      topoCache[key] = features;
      return features;
    }
```
